وظائف النسخة الأولى (V1)

كل وظيفة خادم لازمة لـ V1، لكل الأدوار. V1 حسب وثيقة المنتج = المرحلة ٠ (التأسيس) + المرحلة ١ (الـMVP)، وناتجها «منتج B2C قابل للإطلاق». الوظائف مأخوذة من كود الواجهة ومطابقة مع الـ١٦ ميزة في الوثيقة.

الإصدار V1٢٦ أكتوبر ٢٠٢٦١ نوفمبر ٢٠٢٦ – ٤ مارس ٢٠٢٧

الخلاصة

٦٢ وظيفة لـ V1 في ٩ سبرينتات (١٨ أسبوعًا)، من ١ نوفمبر ٢٠٢٦ إلى ٤ مارس ٢٠٢٧.

  • ٤٩ وظيفة من ميزات المرحلة ٠ و١ في الوثيقة مباشرة.
  • ٩ مش مسمّاة كميزة بالوثيقة، بس بدونها V1 ما بيشتغل (تسجيل، اعتماد المعلّمين، إيقاف حساب، طلبات التواصل).
  • ٤ الوثيقة حاطّتها بمرحلة لاحقة، ونوصي فيها بـ V1: التدقيق، العزل، حدّ كلفة «النجمة»، وموافقة وليّ الأمر (بيانات قُصّر).
  • الافتراض: مطوّرا باك اند اثنان، والمدّة تشمل ربط الشاشات الموجودة بالخادم.

بيضل شغّال كنسخة عرض للتسويق، وبينبني بـ V2 وV3 حسب مراحل الوثيقة.

V2 (المرحلة ٢)

  • امتحان الوحدة، المساعد الذكي، تصحيح المقالي، بنك الأسئلة الكامل
  • تشخيص الفجوات والخطط العلاجية الكاملة، تقارير الأداء
  • الواجبات، التصحيح اليدوي، أداء الفصل، الحضور
  • لوحة إدارة المدرسة: المستخدمون، الصفوف والجداول، التقارير المؤسسية
  • الرسائل والإعلانات، الإشعارات متعددة القنوات، تطبيق PWA

V3 (المرحلة ٣)

  • الإشراف التربوي بكامله
  • المستأجرون، التراخيص، الفوترة وبوّابات الدفع (إلا إذا V1 مدفوع)
  • شاشات «النجمة» والتدقيق والأمان، التكاملات ومفاتيح API
  • التلعيب (النقاط والشارات)، البطاقات والخرائط الذهنية، الاختبارات التكيّفية
  • خارج الوثيقة أصلًا: البحث العام، رسوم المعلّمين، طلبات التسجيل المدفوعة

ملاحظات من الوثيقة

  • F5.2 بتطلب تنبيه الغياب بس الحضور (F7.3) بالمرحلة ٢. بـ V1 التنبيهات على النتائج بس.
  • F5.2 معتمدة على تقارير الأداء (F3.6) والإشعارات (E9) وهدول بالمرحلة ٢. التقرير الدوري بـ V1 ملخّص نتائج بسيط.
  • F2.3 بتذكر السؤال المقالي، بس معيار القبول بيطلب الأنواع الموضوعية بس. المقالي بـ V2 مع تصحيحه.
  • F4.1 «التقويم الدراسي» بـ V1 هو الدروس والاختبارات الجاية، مش الجدول الأسبوعي للمدرسة (V2).
